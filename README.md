# آگاه — سایت و دستیار هوشمند

سایت معرفی اپ «آگاه» + دستیار هوشمند فارسی که روی **Cloudflare Workers AI** اجرا می‌شود (بدون هیچ کلید API بیرونی).

## ساختار
```
wrangler.jsonc        تنظیمات کلودفلر (فایل‌های استاتیک + بایندینگ هوش مصنوعی)
src/worker.js         مسیر /api/chat (دستیار) و /api/health
public/               خود سایت (index.html، استایل، جاوااسکریپت، فونت، img/ اسکرین‌شات‌های اپ)
public/assets/config.js   ← لینک دانلود APK را اینجا بگذار
```

## ۱) آپلود در گیت‌هاب
1. در گیت‌هاب یک ریپوی جدید بساز (مثلاً `agah-site`).
2. محتوای همین پوشه را در ریشه‌ی ریپو آپلود کن (Add file ← Upload files) یا با ترمینال:
```
git init
git add .
git commit -m "Agah site"
git branch -M main
git remote add origin https://github.com/USERNAME/agah-site.git
git push -u origin main
```

## ۲) لینک دانلود
فایل `public/assets/config.js` را باز کن و `apkUrl` را به لینک APK خودت تغییر بده
(مثلاً یک Release در گیت‌هاب بساز، APK را آپلود کن و لینک `releases/latest` را بگذار).

## ۳) اجرا روی کلودفلر (پیشنهادی: Workers + Git)
1. وارد داشبورد کلودفلر شو ← **Workers & Pages** ← **Create** ← **Import a repository** (اتصال به گیت‌هاب).
2. ریپوی `agah-site` را انتخاب کن.
3. تنظیمات بیلد:
   - Build command: **خالی بگذار**
   - Deploy command: `npx wrangler deploy` (پیش‌فرض)
4. **Deploy** را بزن. بعد از چند دقیقه آدرس `https://agah.<حساب‌شما>.workers.dev` فعال می‌شود.

بایندینگ هوش مصنوعی (`AI`) و فایل‌های استاتیک از `wrangler.jsonc` خوانده می‌شود؛ لازم نیست چیزی دستی بسازی.

> اگر ترجیح می‌دهی با خط فرمان دیپلوی کنی: `npm install` سپس `npx wrangler login` و `npx wrangler deploy`.

## ۴) بررسی
- آدرس `/api/health` را باز کن؛ باید `{"ok":true,"ai":true}` ببینی.
- در سایت، نقطه‌ی کنار «دستیار آگاه» باید سبز و «آنلاین» باشد.
- اگر قرمز بود: در Worker، بخش **Settings ← Bindings** مطمئن شو بایندینگ **Workers AI** با نام `AI` وجود دارد (اگر با فایل wrangler دیپلوی شده باشد خودکار است).

## ۵) وصل کردن اپ به سایت
بعد از دیپلوی، آدرس سایت را (مثلاً `https://agah.xxxx.workers.dev`) در یکی از این دو جا بگذار:
- داخل اپ: تب **تنظیمات ← سایت آگاه ← آدرس سایت** (بدون نیاز به بیلد دوباره)
- یا در کد اپ: فایل `lib/config.dart` مقدار `kSiteUrl`

از آن به بعد دکمه‌های «باز کردن سایت» و «دستیار آنلاین» (تنظیمات و تب دستیار) و جمله‌ی «دستیار آنلاین» در چت اپ، سایت را با پارامتر `?from=app` باز می‌کنند و صفحه مستقیم روی دستیار می‌رود.

## ۶) دامنه‌ی دلخواه
Worker ← Settings ← **Domains & Routes** ← Add ← Custom domain.

## نکات
- **سهمیه:** Workers AI سهمیه‌ی رایگان روزانه دارد. مقدارش را در داشبورد (AI ← Workers AI) ببین. مدل پیش‌فرض بزرگ (`llama-3.3-70b`) سهمیه‌ی بیشتری مصرف می‌کند؛ برای صرفه‌جویی در `src/worker.js` مقدار `MODEL` را برابر `@cf/meta/llama-3.1-8b-instruct` بگذار.
- **ضد سوءاستفاده:** در `worker.js` محدودیت اندازه‌ی پیام و نرخ ساده وجود دارد. برای محافظت جدی‌تر، در داشبورد ← Security ← WAF یک **Rate limiting rule** برای مسیر `/api/chat` بساز.
- **شخصی‌سازی دستیار:** متن `SYSTEM_PROMPT` در `src/worker.js` شخصیت و قوانین دستیار را تعیین می‌کند؛ آزادانه ویرایشش کن.
- **حریم خصوصی:** تاریخچه‌ی چت فقط در مرورگر کاربر ذخیره می‌شود و برای تولید پاسخ پیام‌های اخیر به Workers AI فرستاده می‌شود. این را در صفحه هم نوشتم؛ اگر قانون یا سیاست خاصی داری متن را اصلاح کن.
- **تست محلی:** `npm install` سپس `npx wrangler dev` (برای اجرای هوش مصنوعی نیاز به ورود به حساب کلودفلر دارد).
